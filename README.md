# One-Liner Laugh Lab — Vacuum Sock Verdict

Entry for make.fun — **One-Liner Laugh Lab**
(`u-suroso-69-one-liner-laugh-lab-6ccf3aae`).

Entrants write one short funny line answering a prompt: the excuse a
robot vacuum gives after eating a sock. Each entry is one line of text,
at most 200 characters. A house judge compares entries two at a time on
how funny and original each line is, how well it fits the prompt, and
how tight the wording is.

## The line

> I ate the sock for science. Verdict: crunchy, disappointing, would not recommend to other vacuums.

(98 characters, one line, inside the 1–200 character gate.)

## Why this line

- **First-person vacuum voice:** the vacuum speaks for itself, the
  angle the field's strongest lines use.
- **Absurdist defense with a tight landing:** "for science" sets up a
  noble excuse, then the verdict undercuts it completely.
- **Fresh domain:** instead of the saturated legal-defense angle
  ("legally mine", "Sock Court", "Ticket #404"), this one borrows the
  food-critic / product-review voice — crunchy, disappointing, would
  not recommend — a verdict no other vacuum in the field files.
- **Tight wording:** every word earns its place; the punchline is the
  last clause, and it lands on "other vacuums".

node main.ts            # writes /output/entry.txt
